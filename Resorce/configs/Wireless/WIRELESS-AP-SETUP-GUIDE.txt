==================================================================
GLOBALTECH INDUSTRIES LTD. - WIRELESS ACCESS POINT SETUP GUIDE
Complete Wireless Deployment for HQ + 20 Regional Branches
==================================================================

OVERVIEW
--------
Each location receives at least one Cisco Wireless Access Point (AP).
HQ receives 2 APs (one per access switch). Branches receive 1 AP each.
Total APs: 22 (2 HQ + 20 Branches)

All APs use WPA2-PSK for authentication (Packet Tracer compatible).
Wireless clients receive IP addresses via central DHCP (with relay).

Subnet:         10.10.90.0/24 (same VLAN 90)

Packet Tracer Configuration Steps (HQ APs):
1. Place AccessPoint-PT device on the topology.
2. Connect AP Ethernet port to the designated switch port.
3. Click AP -> Config tab:
   a. Port 0 (Ethernet): SSID = GlobalTech-HQ
   b. Authentication: WPA2-PSK
   c. PSK Pass Phrase: GlobalTech@WiFi2026HQ
   d. Channel: 1 (AP-1) or 6 (AP-2)
4. Wireless clients (Laptop-PT with wireless NIC):
   a. Desktop tab -> PC Wireless -> Connect to GlobalTech-HQ
   b. Enter WPA2 passphrase
   c. Set IP to DHCP

==================================================================
WIRELESS SECURITY BEST PRACTICES
==================================================================

1. WPA2-PSK (AES) is used for all access points.
   - In production, WPA2/WPA3-Enterprise with RADIUS is recommended.
   - WPA2-PSK is used here due to Packet Tracer limitations.

2. Each branch has a unique SSID and passphrase.
   - Prevents credential reuse across locations.

3. Wireless clients share the branch LAN subnet.
   - In production, a separate wireless VLAN is recommended.
   - HQ uses a dedicated VLAN 90 for wireless.

4. AP channels are staggered (1, 6, 11) to minimize interference.

5. MAC filtering can be enabled on APs for additional security
   (not configured by default due to management overhead).

6. Guest wireless at HQ uses VLAN 80 (GUEST) with restrictive ACLs:
   - DNS and Web access only
   - No access to internal department VLANs or branch networks

==================================================================
WIRELESS CLIENT PC CONFIGURATION (Packet Tracer)
==================================================================

For Laptop-PT devices with wireless NICs:
1. Click Laptop -> Physical tab
   - Power off, remove Ethernet module (if present)
   - Add WPC300N (wireless module)
   - Power on
2. Desktop tab -> PC Wireless
   - Scan for networks -> Select SSID
   - Enter WPA2 passphrase
   - Connect
3. Desktop tab -> IP Configuration -> DHCP
4. Verify: Command Prompt -> ping 10.10.70.50 (Web Server)
   Should receive reply confirming wireless connectivity.
